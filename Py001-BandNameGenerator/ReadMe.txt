# 🎸 Band Name Generator
A simple beginner-friendly Python project that generates a band name using the user's city of origin and first pet's name.

## 📌 About the Project
The Band Name Generator is a command-line program built with Python. It asks the user two questions and combines their answers to suggest a unique band name.
This project is a great way to practice basic Python programming concepts.

## ✨ Features
- Displays a welcome message.
- Takes user input for their city of origin.
- Takes user input for their first pet's name.
- Combines both inputs to generate a band name.
- Uses Python f-strings to display the result.

## 🛠️ Technologies Used
- **Language:** Python 3
- **Concepts:** `print()`, `input()`, variables, and f-strings

## 🚀 How to Run
1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

If your system uses `python3`, run:

```bash
python3 main.py
```
